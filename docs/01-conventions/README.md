# 프로젝트 컨벤션

이 폴더는 프로젝트의 협업 및 개발 규칙을 관리한다.

## 기본 원칙

- 모든 작업은 브랜치 기반으로 진행한다.
- `main`과 `dev` 브랜치에 직접 push하지 않는다.
- 작업 시작 전 최신 `dev` 브랜치를 반영한다.
- 기능 단위로 작업하고 PR을 통해 리뷰 후 병합한다.
- 기술적 의견이 다르면 근거를 바탕으로 논의한 뒤 다수결로 결정한다.
