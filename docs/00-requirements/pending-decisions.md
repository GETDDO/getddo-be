# 미결정 사항

확정되지 않은 정책과 구현 기준을 기록한다. `[재확인 필요]`와 `[추가 검토 필요]`로 전달된 항목을 임의로 확정하지 않는다.

## 이벤트

- [재확인 필요] 기존에는 중단·취소 모두 응모권을 반환하도록 작성했다. 일시 중단과 취소를 구분함에 따라 일시 중단 시에도 반환할지 확정한다.
- [추가 검토 필요] 일시 중단 후 재개 시 기존 응모 유지, 마감 시각 변경 여부, 재개 가능한 상태와 조건을 정한다.
- [재확인 필요] 반환 대상이 되는 중단의 범위와 반환 완료 시한을 정한다.
- [재확인 필요] 반환 응모권은 '해당 월'까지 유효하다. 해당 월이 원래 차감한 월·취소한 월·반환한 월 중 어느 월인지 확정한다.
- [추가 검토 필요] 중단·취소와 응모가 동시에 발생할 때의 처리 순서 및 월을 넘긴 반환의 만료 처리를 정한다.
- [추가 검토 필요] 취소 가능한 상태, 중단 후 재개할 상태, 재추첨 상태 진입·종료 조건을 정한다.

## 주간 미션 — 보류

- [추가 검토 필요] 미션별 N값, 목표 점수, 보상 응모권 수량.
- [추가 검토 필요] 주간 초기화 요일·시각·시간대.
- [추가 검토 필요] 주차별 달성·보상 가능 횟수 및 지급 방식.
- [추가 검토 필요] 주차 경계를 넘는 연속 출석 인정 방식.
- [추가 검토 필요] 게임 횟수·점수를 게임별로 판단할지, 여러 게임을 합산할지 여부.
- [추가 검토 필요] 유효한 게임 플레이 인정 기준.

## 일회성 미션

- [재확인 필요] 미션이 서비스 공통인지 특정 이벤트에 속하는지, '이벤트 기간'이 어느 기간인지 확정한다.
- [재확인 필요] 장기 연속 출석의 실제 적용 일수를 정한다. 15일·20일은 예시다.
- [재확인 필요] 브랜드 퀴즈는 참여만으로 달성하는지, 정답을 맞혀야 하는지 정한다.
- [추가 검토 필요] 설문 완료 기준, 퀴즈 재도전 기준, 미션별 보상 수량을 정한다.
- [추가 검토 필요] 출석 누락 시 연속 출석 처리 방식을 정한다.
- [추가 검토 필요] 주간 미션 도입 시 장기 출석·주간 출석 미션 간 중복 보상 여부를 정한다.
- [추가 검토 필요] 기준 기간보다 긴 연속 출석 일수를 가진 미션의 등록 허용 여부를 정한다.

## 게임

- [재확인 필요] 일일 보상 제한은 전체 게임 합산 기준인지 게임별 기준인지 확정한다.
- [재확인 필요] 보상 획득에 필요한 게임 플레이 횟수·점수 조건과 일일 기준 시간대를 정한다.
- [추가 검토 필요] 제공할 게임 종류 및 게임별 규칙. 타코야끼 만들기는 후보이며 확정 게임이 아니다.
- [추가 검토 필요] 게임 결과·플레이 횟수의 유효성 검증 방식. 담당: 윤태형.
- [추가 검토 필요] 재시도·중복 결과 제출의 처리 방식. 담당: 윤태형.

## 응모권

- [재확인 필요] 월별 만료 시점의 기준일·시각·시간대를 명시한다. 기존 문구는 '00시'이며, 운영 절에서는 출석과 같은 시간 기준을 적용한다.
- [추가 검토 필요] 만료 직전 지급·차감과 이미 접수 완료된 응모의 월 경계 처리 기준을 정한다.
- [추가 검토 필요] 부정 획득 응모권에 대해서도 반환할지, 별도 처리를 적용할지 정한다.

## 응모와 어뷰징

- [추가 검토 필요] 서버의 '응모 접수 완료 시점'에 해당하는 처리 단계를 구현 설계에서 정의한다. 담당: 석종수. 응모 담당자와 연동 기준을 맞춘다.
- [추가 검토 필요] 구체적인 탐지 조건·시간·횟수 기준을 정한다.
- [추가 검토 필요] 게임 점수에 같은 검토 절차를 적용할지 정한다. 랭킹 보상은 도입 시 별도로 검토한다.
- [추가 검토 필요] 출석·미션·게임의 매크로·봇, 조작된 점수 등 지급 단계의 탐지 기준을 정한다. 게임 어뷰징 탐지는 게임 요구사항과 함께 검토한다. 담당: 석종수.
- [추가 검토 필요] 요청 빈도 제한, 자동화 방지 수단의 적용 여부와 대상 기능을 정한다. 담당: 석종수.

## 추첨과 결과 발표

- [재확인 필요] 자동 추첨 시점에 미검토 탐지 건이 남아 있을 때의 처리 방식을 확정한다. 기존 '15분 안에 검토가 끝나지 않으면 추첨 보류' 문구는 마감 후 즉시 자동 추첨과 충돌하므로 확정 정책으로 적용하지 않는다.
- [재확인 필요] 기존 안은 3등 → 2등 → 1등 순서로 실제 추첨하며, 앞서 당첨된 사용자를 다음 등수 추첨에서 제외한다. 실제 선정 순서인지 화면 발표 순서인지 프론트엔드와 확인한다.
- [추가 검토 필요] 관리자가 시드를 고르거나 반복 실행해 결과를 선택하지 못하도록 시드 생성 주체와 추첨 전 고정·공개 방식을 정한다. 담당: 석종수.
- [추가 검토 필요] 스냅샷 보존 기간과 사용자 탈퇴·개인정보 파기 시 처리 방식을 정한다.
- [재확인 필요] '사용자에게 프론트로 보여주지 않는다'는 재추첨 연출 생략인지, 변경된 결과도 비공개로 하는 것인지 확정한다.
- [추가 검토 필요] 재추첨 후보 범위, 가중치 기준, 후보 부족 처리, 허용 기한, 재발표 방식과 기존 결과 보존 방법을 정한다.
- [재확인 필요] 응모에 차감한 응모권 수를 가중치로 환산하는 계산식, 상한, 추가 배율을 정한다. 담당: 석종수.
- [추가 검토 필요] 등수별 경품 배정 순서와 당첨자를 후속 추첨에서 제외하는 처리 순서를 확정한다.
- [추가 검토 필요] 여러 경품·등수에서 대상이 부족할 때 경품 배정 우선순위를 정한다.
- [추가 검토 필요] 구체적인 마스킹 규칙을 정한다.

## 알림

- [재확인 필요] 시작 알림은 시작 전인지 시작 시점인지, 사전 알림이면 몇 분 전인지 정한다.
- [추가 검토 필요] 시작 알림 대상 판정 시점과 이벤트 일정 변경·취소 시 예약 알림 처리를 정한다.
- [원문 충돌] 한 절에는 이벤트 시작 알림 시점이 미정으로 기재됐지만, 뒤의 알림 절에는 '이벤트 시작 시 1회'와 '시작 전 사전 예고 알림을 제공한다'가 함께 기재돼 있다.
- [원문 확인 필요] 결과 발표 알림의 내용이 `결과 확인 안내 및`에서 끝나 있어 문장이 완성되지 않았다.

## 백오피스

- [추가 검토 필요] 출석 정책의 수정 가능 항목·적용 시점과 미션·게임·보상 정책의 진행 중 변경 제한을 정한다.
- [추가 검토 필요] 수정 가능한 사용자 정보 항목과 권한 범위를 정한다.

## 원문에서 확인되지 않은 항목

- 변경 이력에는 운영 및 시연 15절, 공통 추가 검토 16절, 비기능 요구사항이 언급돼 있지만 전달된 최종 본문에는 해당 절이 포함돼 있지 않다.
- 배너의 이미지 형식·용량 제한은 비기능 요구사항을 참조하지만, 전달된 본문에서는 해당 기준을 확인할 수 없다.
