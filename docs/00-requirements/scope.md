# 구현 범위

## 보류

### 주간 미션

주간 미션은 이번 구현 범위에서 보류한다. 아래 항목은 도입 시 검토할 요구사항이다.

- 매주 초기화되는 반복 미션을 제공한다.
- 미션 내용, 완료 조건, 보상 응모권 수를 관리한다.
- 미션 수행 여부와 보상 지급 이력을 확인한다.
- 같은 미션 달성 건에 대한 중복 보상을 방지하고, 수행 기록과 지급 결과의 일치를 보장한다.

| 미션 | 달성 조건 |
| --- | --- |
| 연속 출석 | N일 연속 출석 |
| 게임 플레이 | 게임 N회 플레이 |
| 게임 점수 달성 | 지정된 목표 점수 이상 달성 |

## 제외

### 관리자 인증 승인

- 미션 인증 제출 및 관리자 수동 승인·반려 기능은 이번 버전에서 제외한다.
- 제출 목록, 일괄 승인·반려, 승인 대기·승인 완료·반려 필터는 구현하지 않는다.
- 기존 응모권 지급 현황·검색 기능은 백오피스에서 제공한다.
- 어뷰징 관리자 검토는 별개 기능으로 유지한다.

### 그 밖의 제외 범위

- 실제 문자·이메일·외부 푸시는 이번 버전에서 제외한다.
- 사용자의 응모 취소는 제공하지 않는다.
- 별도 이의 제기는 이번 버전에서 제외한다.
- 관리자의 응모권 수동 지급·회수 기능은 이번 버전에서 구현하지 않는다.
- 부정 획득이 확인된 응모권의 회수 기능은 제공한다.
- 사용자 요청에 의한 당첨 취소와 임의 재추첨은 제공하지 않는다.
- 주간 랭킹·게임 랭킹 보상은 신규 확정 기능으로 추가하지 않는다.
