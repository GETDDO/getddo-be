# 용어

| 용어 | 정의 및 적용 기준 |
| --- | --- |
| 경품 | 이벤트 당첨 물품. 상품과 혼용하지 않는다. |
| 이벤트 응모 | 이벤트에 신청하는 행위. 출석·게임·설문 행위까지 응모로 바꾸지는 않는다. |
| 응모자 | 이벤트 신청 사용자. 참여자와 혼용하지 않는다. |
| 응모 기간 | 이벤트 신청 가능 기간. |
| 응모권 미사용 이벤트 | 응모권을 차감하지 않는 이벤트. 무료 이벤트라는 표현은 결제와 혼동될 수 있어 사용하지 않는다. |
| 응모권 사용 이벤트 | 응모권을 차감해 응모하는 이벤트. |
| 응모권 차감 | 응모에 따라 응모권 잔액을 줄이는 처리. 응모 행위와 구분한다. |
| 총 응모에 차감한 응모권 수 | 모든 응모에 차감된 응모권 수. 반환 등과 혼동하지 않도록 행위를 명시한다. |
| 지급 | 출석·미션·게임 등에 따른 보상 부여. |
| 차감 이력 | 응모권 잔액 감소 이력. |
| 응모권 만료 | 월별 유효기간 종료에 따른 응모권 처리. 소멸은 처리 의미를 설명할 때만 사용한다. |
| 접수 완료된 응모 | 기술적으로 접수가 완료된 응모. 관리자의 참여 허용 판단과 구분한다. |
| 응모 접수 완료 시점 | 응모의 접수가 완료됐다고 판정하는 시점. 구체적인 처리 단계는 구현 설계에서 정한다. |
| 결과 발표 | 확정된 추첨 결과를 공개하는 행위. |
| 어뷰징 탐지 | 비정상 반복 응모·보상 조작 등을 탐지하는 행위. |
| 사용자당 | 가상 사용자를 포함해 고정 사용자 ID를 기준으로 적용하는 제한 단위. |
| 중단 | 이후 재개할 수 있는 이벤트의 일시 정지. |
| 취소 | 이후 재개하지 않는 이벤트의 최종 종료. |

응모는 이벤트에 신청하는 행위이며, 응모권 차감은 응모에 따라 응모권 잔액을 줄이는 처리다.

이벤트 중단은 재개 가능한 일시 정지이며, 이벤트 취소는 재개하지 않는 종료다.
