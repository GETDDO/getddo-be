# 이벤트 도메인 규칙

## 수정 및 삭제 제한

- 시작 전에는 모든 설정을 수정할 수 있다.
- 진행 중에는 제목·설명·이미지를 포함한 이벤트 정보를 수정할 수 없다.
- 진행 중 경품·응모권 차감 수량·당첨 인원·마감 시각 등 응모 조건을 변경할 수 없다.
- 마감 후에는 이벤트 정보를 수정할 수 없다.
- 시작 전이며 응모 이력이 없는 이벤트만 삭제할 수 있다.
- 이벤트 중단·취소는 이벤트 정보 수정과 구분한다.
- 이벤트 중단은 일시 정지이며, 이후 재개할 수 있다.
- 이벤트 취소는 최종 종료이며, 이후 재개할 수 없다.
- 이벤트 취소 시 해당 이벤트의 응모에 차감한 응모권을 반환한다.
- 응모권 반환은 중단·취소 처리 직후가 아닌 후속 처리로 수행한다.

## 상태 관리

- 진행 예정, 진행 중, 마감, 추첨 결과 확정·발표 대기, 결과 발표 완료, 중단, 취소, 재추첨 상태를 구분한다.
- 시스템은 이벤트 상태를 관리하며, 관리자는 허용된 상태 변경을 수행한다.
- 관리자는 추첨 결과 확정·발표 대기 상태를 결과 발표 완료 상태로 변경한다.
- 관리자는 진행 예정·진행 중·마감 상태의 이벤트를 중단할 수 있다.
- '응모자 없음'과 '추첨 대상자 없음' 종료 상태를 구분한다.

미확정된 중단·재개·취소·반환 정책은 [미결정 사항](../00-requirements/pending-decisions.md#이벤트)에 기록한다.
