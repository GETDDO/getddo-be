# 알림 도메인 규칙

## 수신 방식

- 사용자별 사이트 내 알림함을 제공한다.
- 알림에는 제목, 내용, 생성 시각, 읽음 여부, 관련 이벤트 링크를 포함한다.
- 알림 목록 조회, 개별 읽음, 전체 읽음 처리를 제공한다.
- 실제 문자·이메일·외부 푸시는 이번 버전에서 제외한다.

## 이벤트 시작 알림

- 대상은 해당 이벤트 알림 신청자 중 응모 자격을 충족하는 사용자다.
- 내용은 이벤트 시작 안내다.
- 재개 시 시작 알림을 다시 생성하지 않는다.

이벤트 시작 알림의 정확한 시점은 [미결정 사항](../00-requirements/pending-decisions.md#알림)에 기록한다.

## 결과 발표 알림

- 대상은 해당 이벤트 응모자 전원이다.
- 관리자 결과 발표 시 결과 확인 알림을 생성한다.
- 시작 알림 신청 여부와 관계없이 제공한다.
- 관리자 발표 전에는 당첨 결과를 공개하지 않는다.
- 대상, 내용, 발생 사유, 생성·모의 발송 시각, 처리 결과를 기록한다.

## 공통 처리 기준

- 응모 관련 알림은 시작 알림 신청 여부와 관계없이 제공한다.
- 알림은 비동기로 생성한다.
- 결과 발표는 전체 알림 생성 완료를 기다리지 않는다.
- 동일 발생 건을 재처리해도 알림이 중복 생성되지 않도록 한다.
- 별도의 재개·재추첨 발표는 새로운 발생 건으로 처리한다.
- 생성 실패 시 재시도한다.
- 최종 실패 건은 관리자가 확인하고 재처리할 수 있다.
- 실제 발송은 모킹 처리한다.
