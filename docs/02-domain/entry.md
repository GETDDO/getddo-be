# 응모 도메인 규칙

## 응모 처리

- 응모권 미사용 이벤트는 경품을 선택하지 않고 이벤트에 응모하며 응모권을 차감하지 않는다.
- 응모권 사용 이벤트는 모집 시간 내에 응모권을 차감해 응모한다.
- 가중치 적용 이벤트는 여러 장의 응모권을 차감해 응모할 수 있다.
- 가중치 미적용 이벤트는 응모권 1장을 차감해 응모한다.
- 응모권의 유효기간과 보유 수량을 검증한다.
- 같은 요청의 재시도와 새로운 응모를 구분해 중복 반영을 방지한다.
- 응모권 차감·차감 이력·응모 기록은 함께 성공하거나 함께 실패하도록 처리한다.
- 응모권 미사용 이벤트도 같은 요청의 재시도로 응모 기록이 중복 생성되지 않도록 한다.

## 응모 횟수 및 취소

- 응모권 미사용 이벤트는 사용자당 최대 1회 응모할 수 있다.
- 가중치 미적용 이벤트는 사용자당 해당 이벤트에 1회만 응모하며 응모권 1장을 차감한다.
- 가중치 적용 이벤트는 추가 응모를 허용한다.
- 사용자의 응모 취소는 제공하지 않는다.
- 이벤트 중단·취소에 따른 응모권 반환은 이벤트 도메인 정책을 적용한다.

## 마감 판정

- 서버에서 마감 전에 접수 완료된 응모만 인정한다.
- 정확히 마감 시각부터는 응모할 수 없다.
- 마감 전에 접수 완료된 응모는 응답이 마감 후 도착해도 유효하다.
- 응모권 사용 이벤트는 응모 접수 완료 시점을 기준으로 판단하며, 추첨 시점의 접속 유지는 요구하지 않는다.

## 어뷰징 탐지 및 관리자 검토

- 비정상 반복 응모를 탐지하고 사용자·이벤트·탐지 사유·발생 시각·관련 요청을 기록한다.
- 탐지 사실만으로 자동 제외하지 않는다.
- 관리자는 참여 허용 또는 해당 이벤트의 추첨 대상 제외를 결정한다.
- '참여 허용'은 관리자 검토 결과이며, 응모 접수 완료와 구분한다.
- 검토 상태, 검토자, 검토 시각, 사유를 기록한다.
- 제외 확정 전에 관리자가 사유를 확인·기록한다.
- 제외된 본인에게만 제외 사실과 사유를 안내하고 일반 낙첨과 구분한다.
- 구체적인 탐지 수치 및 다른 사용자 정보는 공개하지 않는다.
- 마감 검토는 마감 전 응모와 관련된 탐지 건을 대상으로 한다.
- 마감 후 단순 접속·재시도로 추첨 대기를 늘리지 않는다.
- 별도 이의 제기는 이번 버전에서 제외한다.

미확정된 접수 완료 시점과 어뷰징 기준은 [미결정 사항](../00-requirements/pending-decisions.md#응모와-어뷰징)에 기록한다.
