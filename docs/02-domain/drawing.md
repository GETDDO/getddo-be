# 추첨 도메인 규칙

## 추첨 대상 확정 및 실행

- 마감 전 접수 완료된 유효 응모를 누락·중복 없이 반영한다.
- 관리자 검토 완료 후 추첨 대상 제외 결과를 반영하고, 유효 응모 처리를 확인해 명단을 확정한다.
- 미검토 건이 없으면 유효 응모 처리 확인 후 명단을 확정한다.
- 응모권 미사용 이벤트는 명단 확정 후 관리자가 수동 추첨을 실행한다. 마감·검토 완료만으로 자동 추첨하지 않는다.
- 응모권 사용 이벤트는 모집 마감 후 자동 추첨한다.

## 근거 보존 및 재현

- 응모자 명단, 응모권 수, 가중치, 조건을 별도 스냅샷으로 보관한다.
- 알고리즘에 필요한 시드 또는 추첨 키, 입력 순서, 버전 등 재현 자료를 보존한다.
- 관리자는 동일 입력·조건으로 결과와 당첨 순서를 재현하고 원본과의 일치를 확인한다.
- 재현·검증 과정에서 원본 결과를 보존한다.
- 사용자에게 추첨 방식과 발표된 결과를 안내한다.
- 구체적인 알고리즘은 구현 단계에서 결정한다.

## 재추첨

- 재추첨은 관리자가 수동으로 실행한다.
- 관리자는 재추첨 사유를 입력한다.
- 재추첨은 이력에 남기며, 최초 추첨과의 연결 관계를 보존한다.
- 사용자 요청에 의한 당첨 취소와 임의 재추첨은 제공하지 않는다.
- 발표 후 자격 미달·어뷰징이 확인되면 해당 당첨자의 당첨을 취소하고 재추첨한다. 취소 대상이 아닌 기존 당첨자는 유지한다.

## 가중치 및 중복 당첨

- 응모권 사용 이벤트는 가중치 적용·미적용 방식으로 구분한다.
- 가중치 적용 이벤트는 여러 장의 응모권을 차감해 응모할 수 있다.
- 가중치 미적용 이벤트는 응모권 1장을 차감해 응모하며 응모자별 추첨 가중치는 동일하다.
- 응모권 미사용 이벤트는 이벤트 단위 응모를 기준으로 추첨하며 응모자별 추첨 기회는 1회다.
- 이벤트 하나에서 동일 사용자의 중복 당첨을 허용하지 않는다. 같은 경품과 다른 경품 모두 동일하게 적용한다.

## 대상 부족 및 결과 관리

- 유효 추첨 대상자가 당첨 인원보다 적으면 전원 당첨시키고 남은 당첨 자리는 미선정으로 처리한다.
- 응모자가 없으면 추첨 없이 '응모자 없음'으로 종료·표시한다.
- 전원 제외되면 추첨 없이 '추첨 대상자 없음'으로 종료·표시하고 본인에게 제외 사유를 안내한다.
- 당첨자 목록, 경품 내역, 당첨 순서, 관리자 실행 이력을 관리한다.
- 최초 추첨과 각 재추첨 실행은 동시 요청·처리 중단 후 재시도에도 각각 하나의 결과만 확정한다.
- 재추첨으로 최초 추첨 결과를 덮어쓰지 않고 이력과 출처를 보존한다.

## 결과 발표

- 추첨 결과는 이벤트 유형과 관계없이 관리자 확인 후 발표한다.
- 추첨 직후 자동 발표하지 않고 발표 대기로 보관한다.
- 발표 전 당첨 결과는 비공개로 유지한다.
- 관리자가 발표를 승인하면 결과를 공개한다.
- 마감부터 발표 전까지 '응모 마감 · 결과 발표 대기'를 표시하고 내부 검토 사유는 공개하지 않는다.
- 대상 없는 종료 표시와 제외 당사자 안내는 별도로 제공한다.
- 발표 결과에는 마스킹한 닉네임과 당첨 경품을 표시한다.
- 공개 화면과 응답 데이터 모두에 마스킹을 적용한다.
- 본인 화면에는 자신의 당첨 여부와 경품을 명확히 표시한다.

미확정된 추첨 순서·시드·재추첨·가중치·마스킹 정책은 [미결정 사항](../00-requirements/pending-decisions.md#추첨과-결과-발표)에 기록한다.
