# 작업 기록: 확정 정책에 따른 보상 테이블 분리 설계

- 작성자 / 날짜: Codex / 2026-09-21
- 관련 이슈 / PR: 생성 후 연결
- 변경 범위: 논리 DB 설계 문서
- 상태: 검토 대기
- 담당자 검토: 사용자 정책 확정, 구현 설계 팀 검토 미확인

## 목적과 변경

[테이블 분리 설계](../03-database/reward-tables.md)에 출석·연속 출석·미션(퀴즈·설문)·게임의 저장 영역과 중복 방지 기준을 정리했다.

최종 사용자 결정으로 미션 반복 주기·문항 버전 재달성 제안을 제거하고, 관리자 수동 신규 등록과 사용자·미션 유일 제약으로 변경했다. 출석 정책의 적용일·월별 단계 보존, 게임 플레이 ID 재시도, 취소 즉시 반환, 일반 지급분·반환분의 다른 만료일도 반영했다.

## 과정과 선택 이유

DB 연결 설정과 기존 사용자·응모권 테이블이 없어 DB 제품·키 자료형을 임의로 정하지 않았다. 이번 변경은 논리 설계이며 DDL·마이그레이션·API 구현은 포함하지 않는다.

## 검증과 남은 일

- `git diff --check` 및 로컬 Markdown 파일·제목 링크 검사를 수행한다.
- 문서 변경으로 로컬 애플리케이션·DB 실행 테스트는 수행하지 않았다. PR의 저장소 필수 CI는 별도로 확인한다.
- DB 제품·참조 키·문항 형식·게임별 데이터 형식과 동시성 제어를 구현 단계에서 설계해야 한다.

## 관련 결정

공용 명세 ADR-008: 순차 질의로 확정한 서비스 정책 일괄 반영. ADR-006의 반복 미션 설계는 최종 정정으로 대체됐다.
