## 고민과 판단

- 이벤트를 먼저 잠그고 실행을 잠근다. 이벤트 ID 사전 조회 뒤 잠금 대기에서 이전 확정의 커밋을 놓치지 않도록 확정 서비스는 `READ_COMMITTED`를 사용한다.
- 최초 통합 테스트에서 불변 결과 엔티티를 INSERT 직후 `refresh`하면 Hibernate의 WRITE 잠금 오류가 발생했다. 결과를 flush 후 detach하고 다시 조회하여 실제 DB 값을 반환하도록 수정했다. 결과·상태 전환 이후의 실패 주입도 실제 JPA persist·flush를 수행하도록 보완했다.
- 현재 스냅샷 계약은 최초 실행용이다. 재추첨의 유지 당첨·대상 자리 계약은 GD-138에서 연결하고 현재 서비스에서 재추첨을 전체 자리 최초 선정처럼 처리하지 않는다. 자동 실행·실패 운영·취소·공개·알림은 별도 범위다.
- 확정 제외 저장 기반은 GD-143, 저장소 연결·경합 검증은 GD-130의 별도 후속 작업임을 Jira 본문에서 확인했다. 해당 미완료를 GD-84·GD-85 완료 차단 조건으로 사용하지 않는다.
