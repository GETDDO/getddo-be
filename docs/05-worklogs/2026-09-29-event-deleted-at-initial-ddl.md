# 2026-09-29 이벤트 논리 삭제 컬럼 초기 DDL 반영

- 작성: Codex (담당자 확인 전)
- 상태: 검토 대기

## 오늘 한 일

- 사용자 요청에 따라 이벤트·배너의 `deleted_at`을 V006 초기 `CREATE TABLE`에 포함하고 V012 추가 마이그레이션을 제거했다.
- 현재 스키마 설명과 Flyway 적용 개수 검증을 V001~V011 기준으로 수정했다. 과거 작업 기록의 당시 V012 언급은 변경하지 않았다.

## 고민과 판단

- 이 변경은 V006을 적용한 DB가 없다는 사용자 설명을 전제로 한다. 이미 적용된 DB가 있다면 변경된 V006 체크섬과 제거된 V012 이력 때문에 Flyway 검증에 실패할 수 있으며, 해당 DB는 재생성이 필요하다.

## 확인 결과 / 막힌 점

- 문서·SQL·테스트의 V012 참조를 정적으로 점검했다. 로컬 Java가 없어 Gradle 테스트·빌드는 실행할 수 없고, Docker API 접근 권한이 없어 DB의 실제 적용 이력은 확인하지 못했다.

## 다음 할 일

- Java·Docker가 가능한 환경에서 빈 MySQL에 V001~V011을 적용하고 이벤트·배너 `deleted_at` 및 Flyway 재실행을 검증한다.
