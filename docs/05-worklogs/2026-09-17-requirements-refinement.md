# 작업 기록: 핵심 기능 용어 통일 및 확정 표현 반영

- 작성일: 2026-09-17 11:37
- 기준: 사용자가 마지막으로 전달한 요구사항 전체
- 상태: 검토 대기
- 담당자 검토: 미확인

## 목적과 변경

- 응모와 응모권 차감을 구분했다.
- 중단과 취소를 구분했다.
- 응모 접수 완료와 관리자 판단을 구분했다.
- 경품, 응모자, 응모 기간, 응모권 지급·차감·만료 등 공통 용어를 통일했다.
- 기존 절 구성을 유지하고 중복된 절 번호를 정리했다.
- 확정된 동작은 서술형으로 정리했다.
- 답변이 없는 정책과 서로 충돌하는 정책은 임의로 확정하지 않았다.
- 주간 미션은 보류, 관리자 인증 승인은 제외로 유지했다.
- 주간 랭킹·게임 랭킹 보상을 신규 확정 기능으로 추가하지 않았다.

## 주요 정리 내용

### 이벤트

- 이벤트 하나당 모집 회차는 하나이며, 모집 마감 후 해당 이벤트의 유효 응모자를 대상으로 추첨하는 것으로 표현을 명확히 했다.
- 단일 경품 추첨과 여러 경품의 등수별 추첨으로 용어를 정리했다.
- 중단은 재개 가능한 일시 정지, 취소는 재개하지 않는 최종 종료로 구분했다.
- 취소 시 반환은 유지하고, 일시 중단 시 반환 여부는 재확인 항목으로 남겼다.
- 반환 응모권의 귀속 월·반환 완료 시한·월 경계 처리는 확정하지 않았다.

### 출석·미션·게임

- 기본 출석은 사용자당 하루 1회, 매일 00:00 UTC 초기화로 통일하고 09:00 KST를 병기했다.
- 일회성 미션의 서비스 공통·이벤트별 소속과 기준 기간은 재확인 항목으로 남겼다.
- 게임 보상은 하루 1회 1장을 유지하고, 전체 게임 합산·게임별 기준 및 획득 조건은 재확인 항목으로 남겼다.

### 응모권과 응모

- 응모권은 특정 이벤트에 종속되지 않는 공통 응모권으로 정리했다.
- 응모권 만료 직전 지급·차감 기준은 월말 이벤트 운영과 구분해 별도 검토 항목으로 남겼다.
- 추첨 대상 제외 시 해당 이벤트 응모의 차감분을 반환하는 것으로 정리했다.
- 응모자 수는 사용자 중복을 제거한 인원으로 정의하고 응모 건수와 구분했다.

### 검토·추첨·재추첨

- 관리자의 참여 허용·추첨 대상 제외 판단과 응모 접수 완료를 구분했다.
- 응모권 사용 이벤트는 모집 마감 후 자동 추첨하는 것으로 정리했다.
- 미검토 탐지 건과 자동 추첨의 관계는 충돌이 있어 재확인 항목으로 남겼다.
- 관리자가 사유를 입력해 수동 재추첨하고, 최초 추첨과의 연결 관계를 보존하는 것으로 정리했다.
- 최초 추첨과 각 재추첨 실행별로 하나의 결과만 확정하며 이전 결과를 덮어쓰지 않는 것으로 정리했다.

### 결과 발표·알림

- 관리자 발표 승인 즉시 결과를 공개하는 것으로 정리했다.
- 발표 상태 변경과 알림 생성 작업 등록의 관계를 관리자 발표 정책에 맞췄다.
- 이벤트 시작 알림의 정확한 시점과 재추첨 재발표 알림의 중복 방지 기준은 확정하지 않았다.

### 백오피스·배너·시연

- 관리자 인증 승인 기능은 제외하고, 응모권 지급 현황·사용자 검색·미션·기간 필터·페이지네이션은 백오피스 기능으로 유지했다.
- 배너 등록·수정·삭제 중복 표현을 정리했다.
- 가상 사용자·더미 데이터 시연을 유지했다.
- 사용자당 제한은 고정 사용자 ID를 기준으로 적용하는 것으로 용어를 통일했다.

## 검증과 남은 일

- 요구사항에 `[재확인 필요]`와 `[추가 검토 필요]`로 표시된 정책은 확정하지 않았다.
- 미결정 항목은 [미결정 사항](https://github.com/GETDDO/getddo-spec/blob/main/00-requirements/pending-decisions.md)에 분리했다. 해당 문서는 이후 공용 명세 저장소로 이전했다.
- 전달된 최종 본문에서 운영 및 시연 15절, 공통 추가 검토 16절, 비기능 요구사항은 확인되지 않았다.
